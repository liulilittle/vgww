## 1. 矩阵测试正确性：**通过**（逐条核验）

### 1.1 `rows_pinned` 累加能否捕获"部分命中"？

`[READ: tests/test_dhcp6.cpp:3316]` `size_t rows_pinned = 0;` 在循环**外**声明。
`[READ: tests/test_dhcp6.cpp:3381-3383]` 只有 `if (leases[0].hostname == want)` 才 `++rows_pinned`。
`[READ: tests/test_dhcp6.cpp:3392]` `CHECK(rows_pinned == kRows);`。

**关键点**：`:3380` 已有逐轮 `CHECK(leases[0].hostname == want)`，它单独就能让 3 个失配行各报一次 FAIL。`:3392` 的累加断言是**第二道闸**——即使将来有人把 `:3380` 的逐轮断言改成"记录而不校验"，累加值仍会因 <4 而红。**双保险成立，部分命中不可漏看。**

**实测印证**：MUT-1a 下 `:3380` 报 3 次 + `:3392` 报 1 次 = **4 FAILURES**，累加行 `rows pinned 1/4`。两道闸都触发了。

### 1.2 4 条循环是否每轮独立 server？

`[READ: tests/test_dhcp6.cpp:3322-3323]` 在 `for` 循环**体内**：`Config config = MakeConfig(); Dhcp6Server server(config);` → **每轮全新实例**。
`:3318-3321` 的注释也明确说明了原因（复用会让第一次 Acquire 就把表折叠掉，后续轮次退化）。

**这一点至关重要**：若复用 server，第 2 轮载入时表里已有第 1 轮折叠后的 1 条记录，`LoadLeases` 会再注入 4 条 → 状态不再是"4 条同 DUID" → 矩阵失效。**每轮独立 server 是矩阵成立的前提，实现正确。**

### 1.3 `CHECK(rows_pinned == kRows)` 对 1/4 是否必然红？

必然。`rows_pinned` 是单调累加，`kRows=4` 是编译期常量（`:3315` `constexpr uint32_t kRows = 4;`）。`1 != 4` → `CHECK` 必失败。无提前 return 路径（`:3327-3329` 的 `continue` 只在 `UpsertBinding` 失败时触发，而非断言成功后）。

### 1.4 顺序无关性（本轮设计核心）

`[READ: tests/test_dhcp6.cpp:3340-3353]` 每轮写入**完整 4 条**（`row=1..kRows`），hostname 为 `HOST-iaid%u`，ip 为 `...:%04X`（0x1001..0x1004，互不相同，避开地址去重）。
`[READ: tests/test_dhcp6.cpp:3366-3368]` `Acquire(kStaticDuid, iaid, now, kAck, std::string())` —— **每轮只请求自己的 iaid**。

⇒ 正确实现：`exact` 命中 → carrier 恒为该行记录 → 4/4。
⇒ MUT-1：carrier 恒为"最后迭代项"，对 4 行**完全相同** → 最多 1 行碰巧命中。

**与桶序无关。这是我上轮证明的方法论点，实现忠实落地。**

### 1.5 一个需要指出的细节（非缺陷，但值得知道）

`:3348-3349` 的 ip 是 `fd00:1122:3344:5566:0000:0000:0000:%04X`，即 `kPrefix`(fd00:1122:3344:5566::) + IID 尾 0x1001..0x1004。
`[READ: tests/test_dhcp6.cpp:323-324]` `MakeConfig()` 的 pool 是 `kPoolStart`(::1000) 到 `kPoolEnd`(::1FFF)。
⇒ 载入的 4 条地址**落在池内**，`InPrefix` 与池检查都通过（`:1360` 的 gate 不丢）。**这是正确的**：若地址在池外会被 `!InPrefix` 丢弃，矩阵就变成 0 条了。
同时 `bound_ip`（`:3311-3313`）= `kPrefix` + `::F0FF`，**在池外**（pool 上界 ::1FFF），这与 runtime 绑定值一致（静态绑定可以给池外地址），且 `:3378` 断言 `leases[0].ip == bound_ip` 通过。**逻辑自洽。**
